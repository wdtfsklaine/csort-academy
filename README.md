# CSORT ACADEMY 2.0

Корпоративная LMS СиСорт. React и Vite, Supabase Auth и PostgreSQL, публикация через GitHub Actions на GitHub Pages.

База и начальный контент: supabase/01-upgrade.sql и supabase/02-content.sql. Скрипт supabase/03-first-admin.sql назначает первого администратора после подтверждения его аккаунта. Версия 1.0 хранится в истории Git; исходные таблицы назначений и результатов сохраняются в Supabase.

Для публикации нужны GitHub Actions Variables SUPABASE_URL и SUPABASE_PUBLISHABLE_KEY. В сборке они передаются с префиксом VITE_. Базовый путь GitHub Pages — /csort-academy/.

Учебные материалы в комплекте — стартовые примеры. Перед запуском для сотрудников необходимо согласовать материалы и хранение персональных данных, настроить подтверждение почты и восстановление доступа, загрузить утверждённые видео и расписание.
