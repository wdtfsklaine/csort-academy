# CSORT ACADEMY · Demo 0.7

Кликабельная демонстрация учебной платформы ООО «СиСорт», готовая для **публикации в GitHub Pages**.

## Что работает

- Главная с контрастной, анимированной dark-tech темой и фирменным логотипом.
- Курс **«Документы без переделок»** (5 уроков, интерактивные вопросы, «Ай, давай проще»).
- **6 тренажёров**: табель, подотчёт, заявка на командировку, имена файлов, записка на премию, поиск ошибок.
- Короткое упражнение по проверке ответа ИИ.
- **2 инструмента**: календарные выходные в командировке, шаблоны названий документов.
- «Мой прогресс»: локальное сохранение завершённых уроков/тренажёров и экспорт CSV.
- Проверки авансового отчёта принимают «бензин», «дорога», «ГСМ», «платный проезд» и денежные суммы с запятыми/точками/пробелами.
- Поддержка смартфонов и настроек уменьшения анимации.

## Важные ограничения

Это **публичная демоверсия**, а не готовая система для учёта 81 сотрудника.

- Нет сервера, пользовательских аккаунтов и общего учёта результатов.
- Прогресс хранится **в браузере** посетителя через localStorage.
- Не размещайте реальные персональные данные, пароли, закрытые документы или сведения о сотрудниках в публичном репозитории.
- Тренажёры используют вымышленные ФИО и учебные ситуации; они не записывают данные в Битрикс/1С.
- В демонстрации использован имеющийся PNG-логотип. Для замены оригинальным SVG отправьте SVG разработчику либо замените импорт логотипа в `src/main.jsx` на свой файл.

## Локально в VS Code на Windows

1. Распакуйте архив в **отдельную папку**. Не затирайте локальный проект с админкой.
2. Откройте папку в VS Code.
3. Выполните:

```powershell
npm.cmd install
npm.cmd run dev
```

Откройте адрес из терминала (обычно `http://127.0.0.1:5173`).

**Тест проверок:** `npm.cmd run test`.
**Сборка:** `npm.cmd run build`.

## GitHub Pages — ссылка для завтрашнего показа

1. В VS Code откройте распакованную папку. В левой колонке откройте **Source Control** → **Initialize Repository** → **Stage All Changes (+)** → введите сообщение `demo 0.7` → **Commit**.
2. Нажмите **Publish Branch / Publish to GitHub**, войдите в GitHub и выберите **Publish to GitHub public repository**. Название: `csort-academy`. Важно, чтобы загрузилась папка `.github/workflows`. Если на GitHub уже создан одноимённый репозиторий, выберите другое имя или свяжите существующий репозиторий вручную.
3. В репозитории на GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. Во вкладке **Actions** найдите workflow **Publish CSORT Academy demo**. После запуска должен появиться зелёный статус. Если workflow не стартовал после настройки Pages, откройте workflow → **Run workflow**.
5. Ссылка появится на странице Settings → Pages:

   `https://ВАШ-ЛОГИН.github.io/csort-academy/`

Имя репозитория может быть другим: GitHub Actions автоматически задаёт `VITE_BASE` равным фактическому имени репозитория. Дополнительно редактировать `vite.config.js` не требуется.

**Важно:** Free GitHub Pages для стандартного бесплатного аккаунта требует публичного репозитория. Проверьте, что компания разрешает публикацию логотипа и учебных материалов.

## Дизайн

Тёмный контрастный tech-интерфейс с шумом, свечением, движущимися орбитами и подсветкой карточек. Это оригинальная реализация в духе Raycast, не копия чужого интерфейса. Анимации отключаются, если система настроена на уменьшенное движение.
